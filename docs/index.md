# SolarCold engineering documentation

Adequate Infosoft's SolarCold Platform combines solar-powered refrigeration, environmental telemetry, electronics, and operational tooling for off-grid cold-chain deployments.

## Start here

- **System design:** review the cold-room architecture and electrical integration before changing component specifications.
- **Firmware:** verify sensor addresses, board pins, APN, device identity, and endpoint settings for each deployment.
- **Monitoring:** configure database credentials and ingestion authentication through server environment variables.
- **Validation:** record calibration and acceptance results for each installed system.

## Safety and deployment

Only qualified personnel should modify mains wiring, refrigeration equipment, batteries, or solar power systems. Bench-test firmware and electronics before field installation. Never publish database credentials or ingestion tokens.
