# Contributing

Adequate Infosoft welcomes focused improvements to the Adequate SolarCold Platform.

1. Describe the operational problem, affected subsystem, and expected outcome.
2. Keep deployment secrets and customer data out of source, logs, screenshots, and fixtures.
3. Include appropriate validation: firmware bench results, PHP checks, documentation builds, or hardware design-rule output.
4. Record relevant assumptions such as board revision, sensor model, supply voltage, PHP version, and database version.
5. Preserve the notices in `LICENSE`, `NOTICE.md`, and third-party packages.

Keep changes reviewable and avoid mixing formatting-only work with behavioral changes. Report security issues according to `SECURITY.md`.
