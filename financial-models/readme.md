# SolarCold financial models

This module contains planning templates for evaluating cold-room capital cost, utilization, operating expense, tariff scenarios, and pay-as-you-store revenue.

## Usage

1. Duplicate the workbook for each deployment.
2. Replace example assumptions with verified local quotations and demand estimates.
3. Document currency, tax, inflation, financing, and energy assumptions.
4. Run base, downside, and upside cases.
5. Review formulas after spreadsheet-format conversion.

Financial templates are planning aids, not accounting, investment, or legal advice. Adequate Infosoft recommends independent review before procurement or financing decisions.
