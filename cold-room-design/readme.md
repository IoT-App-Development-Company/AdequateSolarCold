# Cold-room design package

This module contains architectural and systems-design assets used by the Adequate SolarCold Platform. It includes editable ArchiCAD material, CAD exports, diagrams, renders, and integration references.

## Working with the assets

1. Confirm the required authoring-tool version before editing binary design files.
2. Preserve an untouched release copy before migrating formats.
3. Record dimensions, insulation assumptions, electrical loads, and refrigeration changes in the project change log.
4. Regenerate PDF or image exports after editing source models.
5. Have structural, electrical, and refrigeration work reviewed by appropriately qualified professionals.

The primary editable model is `AdequateSolarCold_ColdRoom_ArchiCAD25.pln`.

## Adequate Infosoft convention

New assets should use `adequate-solarcold-<site>-<discipline>-<revision>` naming and include editable source plus a broadly viewable export.
