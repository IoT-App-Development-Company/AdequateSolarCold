# ArchiCAD source model

This folder contains the editable ArchiCAD 25 architectural model for the Adequate SolarCold cold-room site, including the service spaces and site elements represented in the source design.

## Open and edit

1. Install Graphisoft ArchiCAD 25 or a compatible version from the official Graphisoft distribution.
2. Open `AdequateSolarCold_ColdRoom_ArchiCAD25.pln`.
3. Review library-migration and missing-object warnings before saving.
4. Update plans, 3D views, labels, and schedules as required.
5. Export revised PDF and image deliverables and record the model revision.

Preserve a backup before migrating the model to a newer ArchiCAD format.
